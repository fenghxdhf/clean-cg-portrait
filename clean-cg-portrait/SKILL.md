# 清透CG人像与毛发质感

目标：画面干净、形体清楚、材质可信、视觉层级明确；头发保留细密柔软的真实毛发质感。以用户当前请求为范围，用自然中文描述可见效果。未指定平台时直接给跨平台版本。

## 核心审美

- 去除随机碎点、压缩伪影、过度锐化与过强微纹理，保留五官、衣褶、主要纹样、材质差异和空间关系。柔和来自光照与细节对比的控制，不能靠全图模糊、磨皮或覆盖灰雾实现。
- 大形体的明暗区分保持明确；细小纹理的对比适度降低。以眼神和面部为通常的视觉中心，尊重原构图中的动作、道具或其他叙事焦点。次要区域主要减少内部碎细节，不抹掉轮廓和连接。
- **毛发的整体感来自细密发丝共同形成的体积与光泽。整个表面仍有毛发质感，单根发丝不粗硬、不逐根凸起、不各自拥有刺眼反光和深色阴影。**
- 保留必要的浅层叠压和少量克制的轮廓破形；分组大小自然，不平均切成等大尖撮，不逐块塑造厚实条带。不要把“大面积整体感”误解成光滑实体块，也不要做成塑胶主体外另添几根飘丝。
- 皮肤细腻、微纹理低对比，以柔和漫反射为主，保留克制的自然高光。衣物、金属、薄纱等各保留自身材质。装饰结构完整、连接合理，不用随机纹样补满不清楚的区域。

## 先确定范围与图片角色

原图决定人物身份、年龄感、发色、发型基本设计、服装、配饰、姿态、视角和构图。风格参考只提供材质、光照处理、细节层级与用户需要的风格；不移植参考人物的脸、熊猫发饰、双丸子辫、服装或绿色配色。

“整体去脏”不自动授权瘦脸、换背景、改变服装材质或大幅重新布光；明确要求整体CG风格转换时，才按目标统一造型、光照与材质。“只改头发”只应用头发模块，其他区域保持原样。用户只想整理提示词时不生成图片；明确请求处理图片时使用当前环境实际可用的图像编辑能力。工具不可用时如实说明并交付可用提示，不声称已完成编辑。

雪、泥痕、雀斑、旧化等可辨认的真实场景或人物特征不是生成噪点，默认保留。新输入若缺失影响执行的原图或图片角色不明，才简短澄清；没有风格图也可依据文字标准继续，不虚构看过的图。

## 参考与执行

1. 查看当前原图和用户指定参考。首次使用或结果偏离时，阅读 [原始风格参考说明](references/visual-reference.md)，查看其中第二张；需要比较时再查看其他三张。用户提供的新参考和明确要求优先。
2. 按范围读取并采用 [提示词母版](references/prompts.md)：整体优化用整体母版；只改头发用已确认的毛发模块；反馈纠偏用对应短修正。保留母版的审美约束，替换当前图片相关内容，不机械拼接全部模块。
3. 对用户交付可直接使用的成稿，必要时附少量排除项。没有独立负面词栏的平台，把约束放在同一段末尾。不默认加入模型权重、采样值、软件名或“8K”等标签；不得以名称声称实际用了某软件或已输出某分辨率。
4. 编辑图片时，以明确标注角色的原图及风格图执行；有可见结果才做图像验收。仅交付文字时说明实际交付的是提示词，不能将文本审阅写成生成效果验证。

## 反馈纠偏

| 可见问题 | 调整方向 | 避免的反向偏差 |
| --- | --- | --- |
| 画面碎、脏、颗粒重 | 减少随机高对比微细节、伪影和锐化白边 | 全图磨平、抹掉真实雪粒或磨损 |
| 发丝刺眼、像钢丝 | 降低单丝粗硬边缘、逐丝高光阴影，保留细密毛发 | 消除纤维，只剩光滑大面 |
| 一撮一撮、深沟、重复尖尾 | 减弱独立发束的分界与夸张凸起，保持毛发衔接 | 继续增加分层、穿插或外翘 |
| 厚片、塑胶、表面空滑 | 恢复遍布表面的细密柔软毛发，参考原始风格图 | 再次“合并实体块”或只补几根飘丝 |
| 过于服帖、失去生气 | 保留少量浅层叠压和局部细小不齐 | 满头尖撮、等距分束、张牙舞爪 |

每轮先辨认实际偏差，只改对应模块；替换冲突旧词，不叠加历次版本。连续偏离时重新看最初风格参考，必要时回到原始输入，避免继续以失败结果为唯一依据。

## 验收

正常显示尺寸：人物识别与构图保留；视觉焦点明确；大形体与材质可辨；没有密集随机高对比和无意义装饰。细看头发：毛发贯穿表面、细密柔软，仍有自然层次；既没有根根刺眼，也没有厚片拼接、深沟或塑胶主体加飘丝。结合原图判断真实场景细节是否被误删。低质输入缺失的信息只作合理重建，不保证无损还原或一次完美。
