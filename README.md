# Clean CG Portrait｜AI图片去脏与清透CG质感 Skill

针对**画面肌理、噪点过重的 AI 人像图片**，整理随机碎点、锐化白边、杂乱反光和错误纹理，让画面更干净、柔和、通透，呈现细腻的国漫 3D CG 质感。

**推荐使用 Nano Banana Pro 模型作为图像二次处理工具。**

`clean-cg-portrait` 是一套可复用的**提示词与 Skill 工作流**。它用固定的审美规则、按问题选用的修正模块和明确的验收标准，让降噪去脏的方向更稳定，减少每次重新试词的成本。实际图片处理依赖你使用的 AI 平台及其图像编辑能力；项目不包含独立降噪软件、图像模型或 API 服务。

## 第一次怎么用

**免安装：**打开 TXT，复制全文发给能够理解图片与指令的 AI，再上传原图并说明本次需求。文字版不含参考图片，也不会自动成为平台的永久记忆；没有风格图时，可以直接依据文字标准使用。

**安装版：**解压 ZIP，将完整的 `clean-cg-portrait` 文件夹放入目标环境的技能发现目录，保持 `clean-cg-portrait/SKILL.md` 层级。ZIP 是便携压缩包，不是安装程序；具体目录和加载方式请看安装说明。

调用示例：

> 使用 $clean-cg-portrait，直接处理这张图：整体去脏，保留原来的脸、服装、构图和细密柔软的毛发。

只需要文字时，把“直接处理这张图”改为“为这张图写提示词”。

实际处理时，推荐将整理好的提示词与原图一起交给 Nano Banana Pro，并写清“全图优化”“仅去脏”或“只改头发”。

## 可以处理哪些需求

| 范围 | 处理重点 |
| --- | --- |
| 全图优化 | 整理肌理、光影过渡与材质层次，形成干净通透的 CG 观感 |
| 仅去脏 | 清理生成伪影与过强纹理，保留原有布光、背景和人物设计 |
| 只改头发 | 恢复遍布表面的细密柔软毛发，保留发色、发长、基本发型及其他区域 |

头发尤其强调：细丝共同形成自然的体积与光泽，既避免根根刺眼的“钢丝感”，也避免深沟、厚带和光滑塑胶发片。不能靠塑胶主体外补几根飘丝来代替毛发质感。

## 怎样让结果更稳定

- **先锁定内容。**原图决定人物身份、年龄感、姿态、服装与构图；风格图只提供材质、光照和细节层级参考，不复制参考人物的脸、发饰或配色。
- **去掉干扰，保留结构。**降低随机高对比碎纹理，保留五官、衣褶、主要纹样及材质差异。真实雪粒、泥痕、雀斑与旧化默认保留。
- **柔和仍要清楚。**避免过度锐化，也避免全图磨皮、模糊或灰雾覆盖。每轮只修正实际偏差，替换冲突旧词，不叠加所有历史版本。

拿到图片后，先在正常尺寸检查人物与构图、焦点、形体和材质，再细看头发是否柔软连续、真实场景细节是否被误删。

## 效果与边界

这套规则整理自实际迭代中已获使用者确认的去脏方向与细密柔软 CG 毛发描述，尚无定量评测或跨平台一致性测试。结果会受到原图质量、模型及编辑能力影响，可能需要多轮调整；缺失细节只能合理重建，不保证无损还原或每张图片一次成功。CG 指视觉质感，不代表使用了某款建模或渲染软件。
